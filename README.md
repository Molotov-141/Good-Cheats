# Good Cheats : Site Web Thématique
Bienvenue sur le README du site web Good Cheats. Ce projet est conçu autour d'un thème sombre et moderne, visant à offrir une expérience utilisateur claire et esthétique sur toutes les plateformes.
## 🌟 Fonctionnalités Clés
- Design Responsive : L'ensemble de la mise en page, y compris la barre de navigation, s'adapte parfaitement aux différentes tailles d'écran (mobile, tablette, desktop).
- Navigation Cohérente : Intègre une barre de navigation principale en haut et une barre de liens de navigation en pied de page pour faciliter l'accès aux différentes sections.
- Thème Sophistiqué : Utilisation d'une palette de couleurs sombres et professionnelles (#304178) pour le fond et d'accents de couleurs claires pour une excellente lisibilité.

## 🛠️ Technologies Utilisées
Ce projet est basé sur des technologies web fondamentales.
- HTML5 : Structure sémantique du contenu.
- CSS3 : Styling complet, mise en page responsive (@media queries), et gestion des interactions (menu hamburger).
## 📁 Structure du Projet
Le projet se compose d'un fichier principal, sept pages html et de 6 pages de style.
- Fichier principal : index.html. Description : Contient la structure de la page web (navigation, contenu principal, pied de page).
## 📐 Mise en Page Responsive
- Barre de Navigation
Desktop : Les liens de navigation sont affichés horizontalement et centrés.
Mobile (<= 768px) : Les liens sont masqués par défaut et accessibles via une icône qui, une fois cliquée, ouvre un menu déroulant vertical.
